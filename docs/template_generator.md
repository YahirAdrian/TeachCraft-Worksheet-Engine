# 3. Template Generator

**Source:** [`src/TemplateEngine`](../src/TemplateEngine)  
**Specification:** [`docs/template_generator.md`](./template_generator.md)

The Template Generator combines a PowerPoint template with the structured JSON generated by the AI layer.

It interprets the TeachCraft DSL stored in PowerPoint object names and binds the generated data to the correct template elements.

Typical responsibilities include:

- Loading the original `.pptx` from `template/input/`.
- Parsing the template object tree.
- Resolving DSL directives.
- Binding text values with `bind:`.
- Processing collections with `repeat:`.
- Resolving reusable assets with `lookup:`.
- Replacing image placeholders with `image:`.
- Ignoring decorative or unmanaged elements marked with `ignore`.
- Preserving template layout and styling.
- Producing the final generated `.pptx` in `template/result/`.

Example:

```text
template/input/template.pptx
+ template/content/content.json
        │
        ▼
Template Engine
        │
        ▼
template/result/generated.pptx
```

The Template Engine is responsible for **presentation**, while the AI Generator is responsible for **content**.
